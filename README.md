Para solucionar el Hackathon Final 
Se recomienda formar grupos de máximo 3 personas. En caso de que haya grupos 
impares, mantener un balance equitativo de alumnos de ambos programas en cada 
grupo. 
De acuerdo con todo lo desarrollado en los programas de Back End, el alumno deberá 
entregar el proyecto funcional.  
Además, la comunicación entre los participantes del grupo de ambos programas debe 
ser solamente por API. 

CONSIGNA DEL TRABAJO FINAL: PROYECTO FINAL 
LOGRO DE APRENDIZAJE: Al finalizar, el estudiante desarrolla el Back End de una aplicación e
commerce para vender productos de un rubro a elección.  
1. Descripción de la actividad 
Crea el backend de un ecommerce utilizando NodeJS y NPM, implementando conceptos de 
programación orientada a objetos y avanzados, realizando las operaciones CRUD y la gestión 
adecuada de los datos en la base de datos de manera eficiente y de incluir mecanismos de 
autorización y autenticación, como JWT. 
2. Lineamientos generales 
 Es importante conocer la arquitectura cliente-servidor y las tecnologías relevantes 
para el backend, como servidores y bases de datos. 
 Desarrollar la programación y utilizar la terminal y JavaScript. 
 Importante conocer y aplicar los conceptos avanzados de programación y 
programación orientada a objetos en la implementación del backend. 
 Gestionar los datos en la base de datos. 
3. Entregables: 
El avance del proyecto final debe tener los criterios para la arquitectura de la aplicación. Una 
aplicación funcional en NodeJS, con una estructura de código eficiente y claro. Asi como 
pruebas Pruebas y validación de las funciones de la aplicación para asegurarse de que estén 
funcionando correctamente. 
El entregable final sería una aplicación funcional del backend de un ecommerce. Este 
entregable debe incluir el código fuente, los requerimientos para su funcionamiento y una 
demostración de su funcionamiento en un ambiente de pruebas. 
4. Presentación 
Entregable: 
 Enlace del Repositorio en Github. 
Sustentación: 
 Tiempo: 15 min. 
 A través de un navegador: 
o Mostrar el Código fuente de la Aplicación 
o La implementación de conceptos avanzados de programación y 
programación orientada a objetos en el código. 
o Pruebas y validación de las funciones de la aplicación para asegurarse que 
estén funcionando. 
o Actualizaciones visuales instantáneas, y código escalable.
